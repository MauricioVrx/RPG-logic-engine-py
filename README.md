# Python RPG Logic Engine & QA Framework 🎲🐍

A robust backend logic engine for RPG dice resolution and game mechanics, developed with a strict focus on **Software Engineering** and **QA Automation**.

## 🚀 Project Purpose
This project provides a deterministic and highly tested system for processing complex game rules. Unlike a simple simulator, this engine implements strict data validation (sanitization) and a scalable, object-oriented architecture.

## 🛠️ Tech Stack
* **Language:** Python 3.11
* **Testing Framework:** Pytest (Unit Testing)
* **Project Management:** JIRA (Agile/Scrum Methodology)
* **Data Validation:** Regex (Regular Expressions)
* **Architecture:** Object-Oriented Programming (OOP)

## 🏗️ Technical Features & QA focus
* **Test Coverage:** Exhaustive unit testing implementation to ensure logical integrity.
* **Mocking:** Utilization of `unittest.mock` to simulate dice outcomes and ensure deterministic test results.
* **Data Sanitization:** **Regex-based** input validation to prevent format errors or illegal characters.
* **Error Handling:** Robust exception management for unexpected data flows.

## 📋 Project Management (JIRA)
Development is managed via a JIRA board, organizing work into Sprints and Epics:
* **Epics:** Core Logic Engine, Validation System, QA Infrastructure.
* **Workflow:** Git Flow (Feature Branching).
